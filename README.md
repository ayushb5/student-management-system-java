# Student Management System

Core Java console project using:

- OOP
- Collections
- File Handling
- Exception Handling
- Stream API

Features:

- Add Student
- Update Student
- Delete Student
- Search Student
- Sort Students
- Show Topper
- Students above 80
- Average Marks
- Total students
- Failed Students
